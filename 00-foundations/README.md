# Foundations

Start here if any part of the main handbook feels too fast. Foundations explain the ideas *underneath* everything else, in plain language, with code you can run, so a second-year student (or a motivated beginner) can follow the rest.

| Section | What it covers | Time |
|---------|----------------|------|
| [Setup](setup/README.md) | Install Python, an editor and Git; virtual environments; a first tested project | 30-60 min |
| [Computer basics](computer-basics/README.md) | How a computer runs programs, binary and data representation, memory, stack and heap | 3-4 hours |
| [Math for CS](math-for-cs/README.md) | Exponents and logs, logic and sets, counting and probability, sums and recurrences | 5-6 hours |
| [Python fundamentals](python-fundamentals/README.md) | Variables to classes, in seven lessons with exercises | 10-14 hours |
| [Command line and Git](command-line-and-git/README.md) | Terminal, Git, branching, undoing mistakes, GitHub collaboration | 6-8 hours |

## Suggested order

1. **Setup** (do it first so you can run every example).
2. **Python fundamentals** (skip lessons you already know after reading the "Check yourself" questions).
3. **Computer basics** and **command line and Git** (they pair well with Python practice).
4. **Math for CS** (needed before Big-O and algorithms; read it alongside the complexity part).
5. Move on to [complexity](../01-complexity/big-o/README.md) and the rest of the [index](../INDEX.md).

## Do I need all of this?

| If you... | Then... |
|-----------|---------|
| Have never programmed | Do everything, in order |
| Know another language but not Python | Python fundamentals quickly, then computer basics and Git |
| Are comfortable in Python | Skim; focus on computer basics, math for CS and Git |
| Are preparing for interviews soon | Math for CS (exponents, sums, recurrences) and Git, then jump to [the interview playbook](../09-interview-playbook/README.md) |
