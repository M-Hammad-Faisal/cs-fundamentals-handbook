# Python Fundamentals

A seven-lesson crash course for readers who have seen a little programming but want solid, tested foundations before the rest of the handbook. If you already write Python comfortably, skim the "Check yourself" sections and move on.

| # | Lesson | You will learn |
|---|--------|----------------|
| 1 | [Variables, types and operators](01-variables-types-operators.md) | Names and values, int/float/str/bool, arithmetic, comparison, input/output, f-strings |
| 2 | [Control flow](02-control-flow.md) | `if/elif/else`, `for`, `while`, `break/continue`, nested loops, the counting/searching patterns |
| 3 | [Functions](03-functions.md) | Parameters, return values, defaults, scope, docstrings, recursion, functions as values |
| 4 | [Strings, lists, tuples, dicts, sets](04-strings-lists-dicts-sets.md) | Slicing, methods, comprehensions, counting and grouping, choosing a collection |
| 5 | [Files, modules and errors](05-files-modules-errors.md) | Reading/writing files, CSV/JSON, `pathlib`, imports, `try/except` |
| 6 | [Debugging and testing](06-debugging-and-testing.md) | Reading tracebacks, debugging method, `assert`, `unittest`, `pytest`, regression tests |
| 7 | [Classes: a first look](07-classes-first-look.md) | Objects, attributes, methods, `__init__`, `__str__`, a bank account |

**How to study:** type every example (do not copy-paste), change it, break it on purpose, then do the practice questions before opening the solutions. Run code in the REPL or save it in a `.py` file ([setup](../setup/README.md)).

After this, continue with [command line and Git](../command-line-and-git/README.md), then the main parts of the handbook ([index](../../INDEX.md)). The [modern Python part](../../08-modern-python/README.md) is the advanced sequel.
