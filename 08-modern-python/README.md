# Part 08: Modern Python

Professional Python for working engineers: the language, the tools and the backend stack. Start with the [bridge from Python fundamentals](00-from-fundamentals-to-modern-python.md), then follow the topics below. Some lessons use third-party packages (`pytest`, `hypothesis`, `fastapi`, `sqlalchemy`, `numpy`, `pandas`); each says so at the top. Every code example was run on a current Python (3.15).

## Topics in this part

Read the topics in this order. Each has an overview, detailed lessons, exercises with solutions and a one-page summary (the full map is in the [index](../INDEX.md)).
