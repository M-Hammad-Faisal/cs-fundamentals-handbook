# Revision Schedule (Spaced Repetition)

Memory fades quickly unless you revisit material at growing intervals. Use this schedule for every chapter.

## The rhythm

| Review | When | How long | What to do |
|--------|------|----------|------------|
| Learn | Day 0 | 45 to 90 min | Read the chapter, run the code |
| Practice | Day 0 or 1 | 30 to 60 min | Do the exercises without looking |
| R1 | Day 1 | 10 min | Read the summary, answer "Check yourself" aloud |
| R2 | Day 3 | 10 min | Re-do two exercises from memory |
| R3 | Day 7 | 15 min | Explain the topic out loud as if teaching |
| R4 | Day 21 | 15 min | Solve one new problem on the topic |
| R5 | Day 60 | 15 min | Skim the summary, fix anything fuzzy |

If you forget something at a review, reset that topic to Day 1.

## A weekly template (about 6 hours)

| Day | Focus |
|-----|-------|
| Mon | New chapter (reading) |
| Tue | Exercises for Monday's chapter |
| Wed | New chapter (reading) |
| Thu | Exercises for Wednesday's chapter |
| Fri | R-reviews due this week (summaries and quizzes) |
| Sat | Mixed problem-solving (3 to 5 problems) |
| Sun | Rest, or write up one thing you learned |

## Techniques that work

- **Active recall:** close the page and write the answer before checking.
- **Teach it:** explain a concept to a friend, or write a short post.
- **Code from scratch:** re-implement a linked list or a hash map without notes.
- **Interleave:** mix topics in practice sessions so you learn to pick the right tool.
- **Error log:** keep a list of mistakes and review it weekly.
